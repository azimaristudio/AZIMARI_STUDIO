## 🚀 Sobre o projeto

Este repositório contém o código-fonte do site institucional da **Azimari Studio**.

A Azimari Studio é uma iniciativa voltada ao desenvolvimento de soluções digitais, criando **sites, aplicações e sistemas sob medida** para transformar ideias em produtos digitais funcionais, modernos e alinhados às necessidades de cada negócio.

O projeto do site tem como objetivo apresentar a identidade da organização, seus serviços e sua proposta de valor por meio de uma experiência digital moderna, responsiva e intuitiva.

---

## 💡 Nossa proposta

Na **Azimari Studio**, acreditamos que tecnologia e design devem caminhar juntos.

Desenvolvemos soluções digitais com foco em:

- 💻 Desenvolvimento de sites e aplicações
- 🎨 UI/UX Design
- 📱 Interfaces responsivas
- ⚙️ Sistemas web personalizados
- 📊 Dashboards e visualização de dados
- 🛒 Soluções digitais para negócios
- ☁️ Infraestrutura e tecnologias web

Nosso objetivo é criar experiências digitais que não apenas funcionem, mas que também sejam intuitivas, acessíveis e visualmente significativas.

---
